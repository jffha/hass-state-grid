# 国家电网 Home Assistant 集成

将“网上国网”账户中的历史用电量和月度电费账单接入 Home Assistant。

完成一次配置后，集成会定时更新绑定户号的每日用电量、本月累计电量、账户余额，
以及最近结算月和本年累计的电量、电费；登录 Token 失效时会自动使用已保存的密码重新登录。
日常运行不需要浏览器、官方 App 或 Android 设备。

> [!IMPORTANT]
> 这是社区维护的非官方集成，与国家电网有限公司没有隶属或授权关系。它依赖网上国网 App 的
> 非公开接口，服务端升级后可能暂时失效。请勿用于计费、结算或其他需要法律效力的场景。

## 相比相关项目的优势

- **无需 Docker**：直接作为 Home Assistant 自定义集成运行，不需要额外容器、定时脚本或
  常驻服务；
- **无需 Playwright 或浏览器**：直接调用网上国网 App 接口，不需要启动 Chromium、模拟点击
  网页或维护浏览器登录状态；
- **无需 OCR 或大模型识别验证码**：登录不依赖图形验证码识别，也不会把验证码截图上传给
  第三方 AI 服务；
- **原生 Home Assistant 实体**：不需要额外配置 Home Assistant 长期访问令牌来推送传感器，
  多户号、更新周期、重认证和实体可用性都由集成统一管理；
- **自动维持登录**：Token 过期后自动使用已保存的密码重新登录，仅在服务端明确要求新设备
  验证时才请用户输入短信验证码。

[![打开 Home Assistant 并添加集成](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=state_grid)

## 功能

- 使用网上国网手机号和密码登录；
- 服务端要求新设备验证时，按提示输入短信验证码；
- 支持一个账户下的多个用电户号；
- 查询最近 1–3 个自然月的每日用电量；
- 按实际用电日期导入能源面板统计，支持延迟补报和历史电量修订；
- 提供最新数据日的总电量；
- 提供本月总电量；
- 查询最近结算月的电量和电费；
- 提供本年累计结算电量和电费；
- 区分预付费账户余额和后付费应交金额；
- 在地区接口支持时提供上月抄表读数；
- 默认每 12 小时更新，可配置为 6–24 小时；
- 登录 Token 过期后自动重新登录。

南方电网账户不适用。

## 安装

### 使用 HACS

1. 打开 HACS，进入“集成”。
2. 右上角菜单选择“自定义存储库”。
3. 添加仓库 `https://github.com/stevenjoezhang/hass-state-grid`，类别选择“集成”。
4. 搜索并下载“国家电网”。
5. 重启 Home Assistant。

### 手动安装

1. 下载本仓库。
2. 将 `custom_components/state_grid` 复制到 Home Assistant 配置目录：

   ```text
   <HA config>/custom_components/state_grid/
   ```

3. 重启 Home Assistant。

## 添加账户

1. 进入“设置 → 设备与服务”。
2. 点击“添加集成”，搜索“国家电网”。
3. 输入网上国网登录手机号和密码。
4. 如果收到新设备安全验证短信，继续输入 6 位验证码。

配置成功后，每个绑定户号会显示为一个设备，并创建对应传感器。一个网上国网账户只需添加
一次；同一账户下的多个户号会自动识别。

## 传感器

每个户号当前创建以下实体：

| 实体名称 | 单位 | 说明 |
|---|---:|---|
| 上一日用电量 | kWh | 上游已发布的上一条每日用电量，实际日期以 `latest_date` 为准 |
| 本月用电量 | kWh | 上游月累计值；缺失时由每日记录相加 |
| 上一结算月电量 | kWh | 上一个已经出账周期的结算电量，不是本月实时累计值 |
| 上一结算月电费 | CNY | 上一个已经出账周期的结算电费 |
| 本年累计电量 | kWh | 网上国网月度账单接口返回的本年累计结算电量 |
| 本年累计电费 | CNY | 网上国网月度账单接口返回的本年累计结算电费 |
| 账户余额 | CNY | 预付费余额；后付费账户有可用结余时显示结余 |
| 应交金额 | CNY | 后付费账户当前应交金额；预付费账户显示 `unknown` |
| 上月抄表读数 | — | 最近结算月末的电表读数，仅部分地区提供 |

“上一日用电量”实体包含以下附加属性：

- `latest_date`：当前状态对应的日期；
- `daily_history`：已查询月份的每日记录。

“上一结算月电量”实体还包含：

- `latest_bill_month`：当前状态对应的结算月份；
- `monthly_bill_history`：本年已经出账月份的电量和电费记录。

### Home Assistant 能源面板

每个户号会自动生成一条名为 **“每日用电量（户号后四位）”** 的外部长期统计。
在“设置 → 仪表盘 → 能源”添加电网消耗时，**同一户号必须二选一：要么选择总电量，
要么选择分时电量，不能同时添加。**

- **总电量方式**：只添加“每日用电量（户号后四位）”。
- **分时电量方式**：只添加该户号全部适用时段的“每日谷段用电量”“每日平段用电量”
  “每日峰段用电量”“每日尖段用电量”，不添加“每日用电量”。仅有平、谷的户号选平和谷即可；
  有峰、尖的户号也需添加对应时段，否则会少计用电量。各时段可分别设置电价。

HA 会把添加的电网消耗来源相加，不会自动识别总量与分项的关系。
例如总电量为 117.33 kWh，平段为 87.74 kWh，谷段为 29.59 kWh；三条同时添加，
电网合计就会变成 234.66 kWh，重复计算了同一份用电量。

统计 ID 格式为 `state_grid:<户号标识>_energy`，也可在“开发者工具 → 统计”中找到；
“本月用电量”实体的 `energy_statistic_id` 属性给出了对应的完整 ID。

在集成配置中可额外勾选谷、平、峰、尖的分时统计，默认启用**谷和平**，总电量始终保留。
每个已启用且接口返回有效数据的时段会生成独立的外部长期统计：

| 时段 | 统计名称（以户号后四位 1234 为例） | 统计 ID | 每日接口字段 |
|---|---|---|---|
| 谷（valley） | 每日谷段用电量（1234） | `state_grid:<户号标识>_energy_valley` | `thisVPq` |
| 平（flat） | 每日平段用电量（1234） | `state_grid:<户号标识>_energy_flat` | `thisNPq` |
| 峰（peak） | 每日峰段用电量（1234） | `state_grid:<户号标识>_energy_peak` | `thisPPq` |
| 尖（tip） | 每日尖段用电量（1234） | `state_grid:<户号标识>_energy_tip` | `thisTPq` |

名称不包含接口返回的户名，避免加密字段或过长名称影响显示。
升级后，已启用且有有效每日数据的统计会在下次成功同步时自动更新名称；即使电量没有变化，
也会更新名称。统计 ID 和历史数据保持不变，无需删除统计或重新配置能源来源。

“本月用电量”实体的 `energy_statistic_ids` 属性列出总电量（`usage`）及已启用时段的完整 ID。
分时数据复用同一次每日历史查询，不增加国网请求；未勾选的时段不计算、不写入统计。
取消勾选会保留已有历史；重新启用时补入当前查询窗口内的数据，更早未导入的日期无法补齐。
接口未返回某时段时跳过，不能用总电量减去其他时段推算，也不会填零；有效零电量正常导入。

国网经常延迟发布电量。外部统计使用接口中的实际用电日期（`Asia/Shanghai`），
例如 10 月 13 日才收到的 10 月 11 日电量会计入 11 日，而不是收到数据的 13 日。
重复同步和 HA 重启不会重复累计；历史电量修订、缺失日补报会更新相应日期和后续累计值。
已经导入的日期保存在 Recorder 中，超出后续查询窗口后仍会保留。
缺失、无效、负数及当天尚未完成的数据不导入；有效的零电量会正常记录。

**升级已有能源配置时**，请移除原来的“本月用电量”或“本年累计电量”能源来源，
再按上述二选一方式添加外部统计。集成可以同时保存总电量和分时历史，
但勾选分时统计不会自动修改能源面板的来源配置。
如果已经重复添加，只需在能源配置中移除总量或分项来源，无需删除统计或历史数据。
原来的实体及其历史记录保留，
但它们按刷新时间产生的统计不会自动迁移或纠正。

接口只有每日总量和每日分时汇总，因此能源面板的日/月/年汇总可按真实日期统计，不能还原真实小时分布。
每日电量放在当天 23:00 的统计桶，00:00 提供累计基线；这不是实际在 23:00 用电的测量值。
最近几天可能暂时没有数据，待国网发布后自动补入；HA 时区建议设置为 `Asia/Shanghai`。

“上一日用电量”和“上一结算月电量”是单日或单月历史快照，不是连续累计表值，因此未设置
`state_class`，不会出现在能源面板的正常选择列表中，以防误选。

当天电量通常不会实时出现，截图中 8 月 21 日晚只能看到 8 月 20 日的数据就是正常的上游延迟。
“上一日用电量”会自动采用服务端最新发布的日期，不会把当天缺失值填成 `0`。月度电费则来自
独立的结算账单接口，不根据每日用电量或本地电价估算。

上游缺失的数据会保留为 `unknown`，不会自动填成 `0`。因此，分时、余额或抄表读数为
`unknown` 通常表示该户号或地区没有返回该项数据，不表示整个集成不可用。

## 查询设置

在“设置 → 设备与服务 → 国家电网 → 配置”中可以调整：

| 选项 | 范围 | 默认值 |
|---|---:|---:|
| 查询最近几个月 | 1–3 个月 | 2 个月 |
| 更新间隔 | 6–24 小时 | 12 小时 |
| 启用的分时统计 | 谷、平、峰、尖，可多选或全部取消 | 谷、平 |

增加查询月份会产生更多上游请求。国家电网的每日数据通常不是实时数据，最新日期以实体的
`latest_date` 属性为准。

为补齐跨月后才发布的上月电量，实际同步至少查询当月和上月；将“查询最近几个月”设置为
`1` 时也会查询上月，设置为 `3` 时会查询最近三个自然月。更早且未曾导入的日期不会自动补采。

## 登录和短信验证

- 登录接口通常返回约 15 天的 Token 有效期，但服务端也可能提前使其失效；
- Token 失效后，集成会在后台使用已保存的密码重新登录；
- 请求前会检查设备令牌的 4 小时缓存，按需更新；更新时保留同一设备身份；
- 只有服务端返回新设备验证要求时，才会发送短信验证码；
- 验证码和临时 `codeKey` 不会持久保存。

某些账号或网络环境可能收到 `RK008`，表示服务端安全校验未通过，可能需要额外验证。
这与 `4006` 新设备短信验证不同，不能保证发送普通短信就能解决。
自动重新登录失败后，可在 Home Assistant 的重新认证提示中查看上游错误并点击“继续”重试，
无需删除集成。重新认证沿用原设备身份。如果官方 App 也提示验证，可先在 App 中完成；
但 App 和集成使用不同设备身份，App 验证成功不保证能解除集成的安全校验限制。

## 隐私与安全

为支持自动重新登录，以下内容会保存在 Home Assistant 的
`.storage/core.config_entries`：

- 网上国网手机号和密码；
- 登录 Token；
- 本地生成的设备 profile seed；
- 查询所需的最小户号信息。

Home Assistant 的 config entry 不会额外加密密码。请保护 Home Assistant 配置目录、备份文件
和管理员账户，不要将 `.storage` 上传到公开位置。

本集成不会要求导出官方 App 数据，不携带官方 APK 或 native SO，也不需要 ADB、Frida、模拟器
或浏览器。项目本身不包含遥测或统计上报。

## 卸载

先在“设置 → 设备与服务”中删除国家电网配置项，再通过 HACS 删除集成或手动移除
`custom_components/state_grid`，最后重启 Home Assistant。

## 开发

项目使用纯 Python 实现网上国网 App 请求协议和本地设备 profile。当前版本针对网上国网 Android
3.2.3；App 或服务端协议升级后可能需要同步更新。

运行测试和静态检查：

```bash
uv run --python 3.13 --with pytest --with gmssl==3.2.2 \
  --with cryptography --with aiohttp --with homeassistant==2026.2.3 pytest -q

uv run --with ruff ruff check custom_components/state_grid tests
```

本项目参考了 [ARC-MX/sgcc_electricity_new](https://github.com/ARC-MX/sgcc_electricity_new)
和 [Bpazy/sgcc_electricity](https://github.com/Bpazy/sgcc_electricity) 的用户体验与实体设计。
